# 跨境汇率风险智能预警与避险策略实训工具

面向经管人工智能课程的 USD/CNY 汇率风险识别、智能预警、远期避险策略比较与实验报告工具。

## 当前阶段

仓库已完成重构前初始化，尚未提交业务程序。后续重构必须在独立分支完成并通过测试后合并，不能修改原“熵合科技”仓库。

## 第一版范围

系统只实现 USD/CNY 出口收汇案例，默认情景为：中国制造业出口企业 90 天后收到 1,000,000 USD。

六个核心页面：

1. 实训案例
2. 汇率数据与 AI 模型
3. 外汇风险敞口与智能预警
4. 避险策略沙盘
5. 蒙特卡洛情景模拟
6. 策略评价与实验报告

## 长期约束

- 历史行情、模型评价指标和报告数据必须来自可核验的真实数据及真实计算。
- 不得在真实数据缺失时自动生成、随机补齐或静默替换行情。
- 蒙特卡洛输出必须明确称为“模型生成的教学情景”，不得冒充真实未来行情。
- 教学案例远期报价必须醒目标注，不得描述为实时银行报价。
- AI 报告只能解释现有输入、真实数据和模型结果，不得虚构指标。
- 系统不得残留碳酸锂、库存、元/吨、商品期货套保等原项目业务字段。
- 新项目的代码、数据库、密钥、部署和记忆与原项目完全隔离。

## 数据与模型口径

- USD/CNY 表示 1 美元兑换的人民币元数，单位 CNY/USD。
- 日对数收益率：`r_t = ln(S_t / S_{t-1})`。
- 年化波动率：`σ_annual = σ_daily × √252`。
- XGBoost 预测下一交易日 USD/CNY 水平；训练集/测试集按时间顺序 80%/20% 划分，不随机打乱。
- GARCH(1,1) 估计条件波动率。
- 每次完整情景计算使用 10,000 条路径和固定随机种子。
- VaR、CFaR 与全部策略必须使用同一批人民币收入情景。

4. PR 通过后合并到 `main`，再连接新的 Streamlit App。
