# 重构规格冻结版

## 1. 项目边界

本项目是原“熵合科技”系统的独立迁移分支。允许复用其 Streamlit 页面框架、顶部导航、状态管理、图表和报告导出经验；禁止修改或覆盖原仓库。

第一版只支持 USD/CNY，不扩展 EUR/CNY、JPY/CNY，不建设用户登录、OTP、角色权限、库存、利润、商品期权和商品期货模块。

## 2. 标准案例与统一参数

默认案例：中国制造业出口企业 90 天后收到 1,000,000 USD，以人民币进行成本核算和利润管理。

统一变量：

- A：外币应收金额，USD
- S₀：当前 USD/CNY 即期汇率，CNY/USD
- S_T：到期日实际或模型情景汇率，CNY/USD
- B：企业预算汇率，CNY/USD
- F：教学案例远期结汇报价，CNY/USD
- h：远期套保比例，范围 0—1
- T：距离收汇日的自然日
- R_budget：预算人民币收入，CNY
- R_unhedged：不套保人民币收入，CNY
- R_hedged：远期套保后人民币收入，CNY

A、T、B、F、h 任一变化，所有依赖结果必须失效并重新计算。

## 3. 六页闭环

### 页面1：实训案例

展示企业背景、交易方向、币种、外币金额、结算期限、当前即期汇率、预算汇率和实训任务。允许修改 A、T、B；S₀来自真实数据，不允许伪装成实时数据的手工覆盖。

### 页面2：汇率数据与AI模型

- 使用同一套真实 USD/CNY 日频数据。
- 展示历史汇率、日对数收益率和20日滚动年化波动率。
- GARCH(1,1)估计和预测条件波动率。
- XGBoost统一预测下一交易日 USD/CNY 水平。
- 显示预测值、风险状态、MAE、RMSE、方向准确率和特征重要性。
- 数据按时间顺序前80%训练、后20%测试，禁止随机打乱和未来数据泄露。

### 页面3：风险敞口与预警

识别出口企业的美元应收敞口，计算预算人民币收入、未套保参考收入、相对预算收入偏差、95% VaR、95% CFaR和Risk Ratio。

内部教学预警规则：

- Risk Ratio < 2%：低风险
- 2% ≤ Risk Ratio < 5%：中风险
- Risk Ratio ≥ 5%：高风险

必须声明该阈值不是监管部门、银行或金融机构的统一标准。

### 页面4：避险策略沙盘

首版仅比较“不套保”和“远期结汇”。h支持0%—100%连续调整，并提供0%、25%、50%、75%、100%快捷比例。

公式：

- R_budget = A × B
- R_unhedged = A × S_T
- R_hedged = A × [hF + (1-h)S_T]
- Hedge Effect = A × h × (F-S_T)

F必须标注为“教学案例远期报价”，不是实时银行报价。

### 页面5：蒙特卡洛情景

- 根据用户T采用统一自然日—交易日换算。
- 使用真实历史数据估计的漂移与GARCH波动率参数。
- 每次完整计算生成10,000条未来教学情景路径。
- 设置固定随机种子，确保重复输入可复现。
- 页面仅展示部分路径，但所有指标基于完整10,000次结果。
- 输出到期汇率、人民币收入分布、平均收入、5%分位收入、标准差、VaR、CFaR和风险下降幅度。

### 页面6：策略评价与报告

比较0%、25%、50%、75%、100%远期套保的平均收入、CFaR、收入波动和风险下降。学生选择最终比例并填写理由。

报告至少包含：案例信息、真实数据来源/范围/更新时间、模型及真实测试集指标、风险敞口、预警、全部策略结果、学生选择、理由和系统评价。优先PDF，同时保留HTML。

## 4. 计算口径

- r_t = ln(S_t / S_{t-1})
- σ_annual = σ_daily × √252
- MAE、RMSE、方向准确率必须由真实测试集结果计算
- Loss_i = max(R_budget - R_i, 0)
- VaR₉₅ = Q₉₅%(Loss)
- CFaR₉₅ = max[R_budget - Q₅%(R), 0]
- Risk Ratio = CFaR₉₅ / R_budget

所有比例必须使用同一批到期汇率情景比较。

## 5. 简化假设

第一版不纳入手续费、授信成本、保证金成本、提前交割、违约风险、税费及其他交易摩擦。远期策略主要评价现金流稳定性和尾部风险控制，不简单评价为盈利或亏损。

## 6. 数据真实性

- 历史数据必须公开、稳定、可追溯，并显示来源、范围和更新时间。
- 训练、测试、图表、波动率和情景参数必须来自同一套基础数据。
- 数据失败时停止计算；不得随机补齐、自动造数或显示预设模型指标。
- 可以使用上次成功下载并注明日期的真实数据快照作为断网后备。
- 模型生成路径必须明确标为教学情景，不得称为真实行情。
