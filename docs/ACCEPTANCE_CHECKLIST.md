# 第一版验收清单

## Next.js / FastAPI 迁移

- [x] Next.js 六模块前端可独立构建
- [x] FastAPI 健康检查、行情、分析和报告接口通过
- [x] 新前端不依赖 Streamlit 会话与组件
- [x] 修改 A、B、F、h 后在同一终值样本上即时重算
- [x] 修改 T 后明确要求重新生成路径
- [ ] 桌面与移动端均无横向溢出或关键控件遮挡
- [x] 滚动入场动效尊重 `prefers-reduced-motion`

## 项目隔离

- [x] 只修改`fx-risk-training`仓库

- [x] 不依赖原项目账户、OTP和业务数据
- [x] 全站不存在碳酸锂、库存、元/吨、商品期货、期货手数等旧字段

## 数据

- [x] 仅使用USD/CNY
- [x] 页面显示数据来源、时间范围和更新时间
- [x] 行情失败时停止计算
- [x] 断网后备仅为已核验真实快照，并显示快照日期
- [x] 图表保留全量真实历史；XGBoost、GARCH和情景参数来自同一真实数据源的最近五年窗口

## AI模型

- [x] XGBoost只预测下一交易日汇率水平
- [x] 时间顺序80%/20%划分
- [x] 不随机打乱
- [x] 无数据泄露或前视偏差
- [x] MAE、RMSE、DA来自真实测试集
- [x] GARCH确实拟合真实收益率

## 业务公式

- [x] R_budget、R_unhedged、R_hedged公式正确
- [x] VaR基于相对当前即期折算价值的汇率损失；CFaR基于相对预算收入的现金流缺口，二者使用同一批收入结果但不再退化为同一公式
- [x] Risk Ratio阈值和教学声明正确
- [x] F醒目标注为教学案例远期报价
- [x] 不把套保简单描述为盈利或亏损
