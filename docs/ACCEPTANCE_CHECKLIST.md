# 第一版验收清单

## 项目隔离

- [ ] 只修改`fx-risk-training`仓库
- [ ] 不引用原项目Supabase URL、Key或表
- [ ] 不依赖原项目账户、OTP和业务数据
- [ ] 全站不存在碳酸锂、库存、元/吨、商品期货、期货手数等旧字段

## 数据

- [ ] 仅使用USD/CNY
- [ ] 页面显示数据来源、时间范围和更新时间
- [ ] 行情失败时停止计算
- [ ] 断网后备仅为已核验真实快照，并显示快照日期
- [ ] 训练、测试、图表、GARCH和情景参数来自同一套数据

## AI模型

- [ ] XGBoost只预测下一交易日汇率水平
- [ ] 时间顺序80%/20%划分
- [ ] 不随机打乱
- [ ] 无数据泄露或前视偏差
- [ ] MAE、RMSE、DA来自真实测试集
- [ ] GARCH确实拟合真实收益率

## 业务公式

- [ ] R_budget、R_unhedged、R_hedged公式正确
- [ ] VaR和CFaR使用同一批人民币收入结果
- [ ] Risk Ratio阈值和教学声明正确
- [ ] F醒目标注为教学案例远期报价
- [ ] 不把套保简单描述为盈利或亏损

## 联动

- [ ] 修改A后全部金额及风险指标变化
- [ ] 修改T后预测期限和路径长度变化
- [ ] 修改B后预算、损失、VaR、CFaR变化
- [ ] 修改F后远期策略结果变化
- [ ] 修改h后收入分布和风险下降变化

## 情景计算

- [ ] 每次完整计算使用10,000条路径
- [ ] 固定随机种子
- [ ] 同组输入结果可复现
- [ ] 图中可以抽样，但指标使用完整结果
- [ ] 页面明确标注为模型生成的教学情景

## 报告与稳定性

- [ ] PDF稳定生成
- [ ] HTML备用输出
- [ ] 报告包含案例、数据、模型、敞口、预警、策略、学生选择与理由
- [ ] 本地reports目录可保存和重新打开报告
- [ ] 无效输入显示明确中文提示
- [ ] GitHub测试通过后才合并到main
